# SUNLIGHT 技术说明

## 1. 系统功能

本工程用于太阳能充电、储能电容管理和 LED 恒流控制，主要功能包括：

- 根据太阳能充电电流判断白天或黑夜。
- 白天关闭 LED，并根据 VBAT 状态进行充电。
- 黑夜停止充电，并在电池保护允许时驱动 LED。
- LED 电流支持 0～300 mA 设置，步进为 25 mA。
- OLED 显示运行模式、VBAT、日夜状态、充电状态及 LED/充电参数。
- 充电通路与 LED 通路互锁，避免两条功率通路同时导通。

## 2. 主要信号

| MCU 引脚 | 信号 | 功能 |
| --- | --- | --- |
| PA0 | ADC_VBAT | 采集 VBAT 电压 |
| PA2 | ADC_ILED | 采集 LED 电流 |
| PA3 | ADC_ICHARGE | 采集充电电流，并用于 DAY/NGT 判断 |
| PB0 / TIM3_CH3 | 充电控制 | 通过 C8T6 控制并联分流 MOS Q3 |
| PB1 / TIM3_CH4 | LED 控制 | 反相控制 LED MOS |
| PB5～PB8 | S1～S4 | 模式、定时和电流调节按键 |
| PB10 / PB11 | I2C2 | OLED 的 SCL/SDA |
| PC13 | 状态灯 | 正常时呼吸，故障时快速闪烁 |

PB0 为高电平时，C8T6 导通并拉低 Q3 栅极，Q3 关断，允许太阳能向 VBAT 充电。PB0 为低电平时，Q3 导通并分流太阳能输入，停止充电。

## 3. 白天和黑夜判断

日夜判断只使用 ADCICHARGE：

1. 关闭 LED，并使充电与 LED 功率通路进入安全状态。
2. 关断 Q3，使太阳能输入能够向 VBAT 提供电流。
3. 若此前处于分流状态，等待输入源恢复，并持续检查 VBAT 过压。
4. 对 PA3 的 ADCICHARGE 连续采样并计算充电电流。
5. 充电电流不小于 50 mA时判定为 `DAY`，否则判定为 `NGT`。

上电后会尽快执行首次检测。正常情况下，白天约每 5 秒复检一次；黑夜或充电完成状态约每 30 秒复检一次。为保安全，不会频繁执行判定，以免电容过度充电损坏电容。检测期间 LED 保持关闭。

## 4. 充电控制

充电状态包括：

- `IDLE`：等待满足充电条件。
- `BULK`：以较高占空比充电。
- `CV`：随 VBAT 上升逐步降低有效充电占空比。
- `REST`：关闭充电后测量静置电压。
- `DONE`：充电完成。

主要控制条件：

- VBAT 不高于 7.8 V 时进入 BULK，目标有效充电占空比为 90%。
- VBAT 达到 7.8 V 后进入 CV，并在 7.8～8.2 V 范围内逐步降低充电占空比。
- VBAT 达到 8.2 V 时立即关闭充电并进行静置确认。
- VBAT 不低于 8.2 V、充电电流持续低于 100 mA 约 5 秒后进入静置确认。
- 静置电压满足完成条件后进入 `DONE`；电压下降到重启门限后重新充电。

OLED 上的充电占空比表示最终"允许充电"的有效比例，不是单纯的 PB0 电平比例。充电采用分段导通方式，使外部限流电源和储能电容有足够的恢复时间。

## 5. LED 控制

LED 默认目标电流为 300 mA，可在 0～300 mA 范围内调节：

- S3：减小 25 mA。
- S4：增加 25 mA。
- 0 mA：保持 LED 关闭。

上电后 300 mA 目标采用直接导通；第一次调节电流后进入 PA2 电流闭环。程序根据目标值和实测电流逐步调节反相 PWM，占空比显示采用 LED 实际导通比例。

VBAT 低于 6.0 V 时关闭 LED；VBAT 恢复到 6.4 V以上并稳定后重新允许 LED 工作。无论 AUTO、定时还是手动模式，白天状态都会禁止 LED 输出，LED仅在夜晚时允许点亮。

## 6. 按键功能

| 按键 | 功能 |
| --- | --- |
| S1 | 在 AUTO、ON、OFF 三种模式之间切换 |
| S2 | 请求定时点亮，持续约 10 秒 |
| S3 | LED 目标电流减小 25 mA；0 mA 后回到 300 mA |
| S4 | LED 目标电流增加 25 mA；300 mA 后回到 0 mA |

所有 LED 点亮请求仍受日夜判定、VBAT 低压保护、ADC 状态和功率通路互锁限制。

## 7. OLED 显示

OLED 每 500 ms 刷新一次。开机初始化时会短暂显示 `SUNLIGHT R12`，进入主循环后固定显示四行运行信息。

### 7.1 第一行：版本、工作模式、LED 实际状态和运行时间

显示格式：

```text
R12 <MODE> <LED><SSSS>
```

例如：

```text
R12 AUTO ON 0123
R12 ON OFF0456
R12 TIME ON 0789
```

各字段含义如下：

| 显示符号 | 含义 |
| --- | --- |
| `R12` | 当前固件功能版本标识。 |
| `AUTO` | 自动日夜模式。检测为 `DAY` 时请求关闭 LED；检测为 `NGT` 时请求点亮 LED。是否真正点亮仍受 VBAT 低压保护、ADC 状态、充电静置和功率通路互锁限制。 |
| `ON`（模式位置） | 手动点亮请求模式，由 S1 切换得到。它只表示"请求 LED 点亮"，不能绕过白天禁亮、低压保护、ADC 故障或功率通路保护。 |
| `OFF`（模式位置） | 手动关闭模式，不再请求 LED 点亮。 |
| `TIME` | S2 启动的约 10 秒定时点亮请求。计时结束后自动进入 `OFF` 模式。该请求同样不能绕过白天禁亮和其他保护。 |
| `ON`（模式后的状态位置） | LED MOS 当前已经产生物理输出，LED 通路实际处于导通状态。 |
| `OFF`（模式后的状态位置） | LED 当前没有物理输出。即使模式为 `ON` 或 `TIME`，也可能因为白天、低电压、日夜状态未知、ADC 故障、充电静置或通路切换而显示 `OFF`。 |
| `SSSS` | 系统上电后的累计运行秒数，显示范围为 `0000`～`9999`，超过后从 `0000` 重新循环。LED 状态为 `OFF` 时，实际屏幕会紧接着显示数字，例如 `OFF0456`。 |

因此，`R12 ON OFF0456` 并不矛盾：第一个 `ON` 表示软件正在请求点亮，第二个 `OFF` 表示保护逻辑尚未允许 LED 真正输出。

S1 每按一次依次切换：

```text
AUTO → ON → OFF → AUTO
```

### 7.2 第二行：VBAT 电压和 LED 低压保护许可

显示格式：

```text
BAT x.xxV ON
BAT x.xxV OFF
```

| 显示符号 | 含义 |
| --- | --- |
| `BAT` | 储能电容或电池端的 VBAT 电压。数值经过 ADC 分压换算、实测校准和滤波，以伏为单位显示两位小数。 |
| `V` | 电压单位伏特。 |
| `ON` | VBAT 低压保护已经放行，电压条件允许 LED 工作；这不代表 LED 此刻一定点亮。 |
| `OFF` | VBAT 低压保护未放行，LED 必须关闭。VBAT 低于 6.0 V 时立即进入该状态。 |

从 `OFF` 恢复到 `ON` 需要 VBAT 高于 6.4 V 并连续稳定约 1 秒。6.0～6.4 V 之间保持原状态，形成滞回，避免 LED 在门限附近频繁开关。

注意：第二行的 `ON/OFF` 表示"电池电压是否允许 LED 工作"，第一行的 `ON/OFF` 表示"LED 是否真的在输出"，两者含义不同。

### 7.3 第三行：日夜判断和充电状态

显示格式：

```text
SOL DAY BULK
SOL NGT IDLE
SOL --- IDLE
```

| 显示符号 | 含义 |
| --- | --- |
| `SOL` | 太阳能输入及充电控制模块标识。当前版本不再显示 SOLAR 电压。 |
| `DAY` | 判定为白天。程序在释放 Q3 后检测到 ADCICHARGE 不小于 50 mA。白天禁止 LED 输出，并允许充电状态机根据 VBAT 决定是否充电。 |
| `NGT` | `NIGHT` 的缩写，表示判定为黑夜。检测到的充电电流小于 50 mA，此时停止太阳能充电，并允许 LED 按模式和保护条件工作。 |
| `---` | 日夜状态尚未得到有效检测结果，常见于刚上电、正在重新检测、ADC 数据无效或功率通路尚未稳定。状态未知时 LED 不会点亮，正常充电控制也不会直接放行。 |
| `IDLE` | 充电空闲或等待状态。当前没有进入 BULK/CV 充电，可能正在等待有效白天状态、合适的 VBAT 或重新启动条件。 |
| `BULK` | 大电流充电阶段。VBAT 较低时采用较高的有效充电占空比。 |
| `CV` | 恒压调节阶段。随着 VBAT 接近上限，程序逐步降低有效充电占空比。 |
| `REST` | 静置确认阶段。程序暂时停止充电，等待端电压稳定后判断是否真正充满。 |
| `DONE` | 充电完成状态。充电保持关闭，直到 VBAT 下降并稳定达到重新充电条件。 |

如果编译时关闭太阳能充电功能，第三行会显示 `SOL DISABLED`；正常交付版本启用了太阳能充电。

### 7.4 第四行：LED 参数或充电参数

第四行会根据当前日夜及功率通路状态在两种格式之间切换。

#### LED 参数格式

```text
Lxxx/yyy Pzz%
```

例如：

```text
L288/300 P100%
```

| 显示符号 | 含义 |
| --- | --- |
| `L` | LED 电流信息标识。 |
| `xxx` | PA2/ADCILED 测得并经过校准、滤波后的 LED 实际电流，单位为 mA。 |
| `/` | 分隔实际电流和目标电流。 |
| `yyy` | 用户设定的 LED 目标电流，范围为 0～300 mA，S3 步减、S4 步进，每次改变 25 mA。 |
| `P` | LED 的物理导通占空比。由于 PB1 后级为反相驱动，程序已经换算成"LED 实际导通比例"后再显示。 |
| `zz%` | LED 导通占空比，范围为 0%～100%。`P100%` 表示 LED MOS 已达到最大连续导通；它不保证实际电流一定达到目标值，实际电流还会受 VBAT、LED 压降、MOS、二极管和接线压降影响。 |

夜晚时即使低压保护使 LED 关闭，第四行仍可能显示该格式，此时通常会看到实际电流接近 0 mA、`P0%`。

#### 充电参数格式

```text
Dxx% CyyymA
```

例如：

```text
D 90% C185mA
```

| 显示符号 | 含义 |
| --- | --- |
| `D` | 充电"允许导通"的有效占空比。 |
| `xx%` | 充电状态机请求的有效充电比例。它表示最终允许太阳能向 VBAT 充电的时间比例，不是 PB0 原始高低电平比例，也不是某一瞬间 Q3 的状态。 |
| `C` | 充电电流标识。 |
| `yyy` | PA3/ADCICHARGE 测得并经过滤波后的平均充电电流，单位为 mA。 |
| `mA` | 电流单位毫安。 |

`D0%` 只表示当前没有正常充电导通时间，可能原因包括黑夜、`IDLE`、`REST`、`DONE`、日夜检测、VBAT 保护或功率通路互锁，并不一定表示故障。

### 7.5 异常显示

```text
ADC ERROR
```

表示至少一个必要 ADC 通道没有得到有效数据。程序会进入安全状态，关闭正常充电输出和 LED 输出，避免使用错误测量值继续控制功率通路。

## 8. 安全机制

- 充电通路和 LED 通路切换时先进入两路关闭状态，再等待安全死区。
- ADC 读取失败时关闭充电和 LED。
- 日夜状态未知时关闭 LED，并暂停正常充电控制。
- 太阳能探测期间持续检查 VBAT，避免探测过程造成过压。
- OLED I2C 异常时执行总线恢复，不改变功率通路保护逻辑。
- 系统错误时 Q3进入分流状态，同时关闭 LED。

### 补2. 硬件电路设计概述（基于PCB技术文档与代码验证）

#### 2.1 系统拓扑

```
太阳能板(SOLAR+/SOLAR-) → 1N4007防反二极管 → VBAT(储能电容/电池)
                                    ↓
                            Q3并联分流MOS(由PB0→C8T6控制)
                                    ↓
                            VBAT → LED通路MOS → LED负载
```

#### 2.2 运放电流采样电路

两个 LM358 运放均配置为同相放大器，增益均为 10 倍（`LED_CURRENT_SENSE_GAIN 10L`、`CHARGE_CURRENT_SENSE_GAIN 10L`）：

- **ILED采样**：采样电阻 1Ω（`LED_CURRENT_SHUNT_MILLIOHMS 1000L`），流经 LED 的电流在采样电阻上产生压降，经 LM358 放大10倍后送入 PA2。满量程计算：300mA × 1Ω × 10 = 3.0V，在ADC 3.3V量程内安全。
- **ICHARGE采样**：采样电阻 0.5Ω（`CHARGE_CURRENT_SHUNT_MILLIOHMS 500L`），充电电流在采样电阻上产生压降，经 LM358 放大10倍后送入 PA3。

#### 2.3 VBAT分压采样

VBAT 通过分压电阻网络接入 PA0。分压比由 `BATTERY_VOLTAGE_SCALE_NUMERATOR(147)` / `BATTERY_VOLTAGE_SCALE_DENOMINATOR(47)` ≈ 3.128:1。当 VBAT=8.45V 时，PA0 电压约为 8.45 / 3.128 ≈ 2.70V，在 ADC 3.3V 量程内安全。

#### 2.4 PWM频率配置

TIM3 用于产生充电控制（CH3）和 LED 控制（CH4）的 PWM 信号：
- 时钟源：72 MHz（APB1定时器时钟，因 APB1 分频为2故定时器时钟倍频）
- 预分频器：71（`TIM3.Prescaler=71`），计数频率 = 72MHz / 72 = 1MHz
- 自动重载值：999（`TIM3.Period=999`），PWM 频率 = 1MHz / 1000 = **1 kHz**
- PWM分辨率：1000级（`PWM_FULL_SCALE 1000U`），约 0.1% 步进精度

#### 2.5 功率MOS驱动链

- **充电通路（PB0 → Q3）**：PB0 输出 0-3.3V PWM → C8T6（小信号NMOS，作为电平转换）→ Q3 栅极。PB0高电平 → C8T6导通 → Q3栅极拉低 → Q3（PMOS或P-ch配置）关断 → 允许充电。PB0低电平 → C8T6关断 → Q3导通 → 分流太阳能输入 → 停止充电。
- **LED通路（PB1 → LED MOS）**：PB1 输出 0-3.3V PWM → 反相驱动级（PCB技术文档提到的"反相电压转换模块"，将0-3.3V上拉至0-5V并反相）→ IRF540N栅极。PB1高电平 → 反相后低电平 → LED MOS关断 → LED灭。PB1低电平 → 反相后高电平(~5V) → LED MOS导通 → LED亮。代码中 `LED_MOS_OFF_COMPARE = PWM_FULL_SCALE` = 输出绝大部分时间高电平 = LED安全关闭。

**注意**：IRF540N 的 Vgs(th) 为 2-4V，完全导通需要约 10V。使用 5V 栅极驱动时 MOS 不完全导通，但实测在 0.5A 以内充电/LED电流下可以正常工作。

#### 2.6 -5V偏置电源

LM358 需要 -5V 偏置电压以支持接近 0V 的输入共模范围（电流采样电阻压降可能很小）。采用 ICL7660N 电荷泵芯片，从外接 +5V 电源产生 -5V 电压供给 LM358 的 VEE 引脚。

### 补3. ADC采样策略详解

#### 3.1 同步PWM采样

为避免 PWM 开关噪声干扰 ADC 读数，代码实现了"与 PWM 周期同步的平均采样"（`ReadAdcAverage()`）：
- 等待 TIM3 计数器回绕（PWM周期开始）
- 在一个完整 PWM 周期（1ms）内均匀分布 20 个采样点（`ADC_PWM_PHASE_SAMPLES 20U`）
- 对 20 次采样取算术平均

此方法有效滤除了 PWM 开关产生的周期性噪声。

#### 3.2 软件低通滤波

三种测量量各有独立滑动窗口滤波器：

| 测量量 | 滤波器窗口 | 宏定义 |
| --- | --- | --- |
| VBAT电压 | 40采样（~2s @ 50ms控制周期） | `BATTERY_VOLTAGE_FILTER_SAMPLES 40U` |
| LED电流 | 4采样（~200ms） | `LED_CURRENT_FILTER_SAMPLES 4U` |
| 充电电流 | 40采样（~2s） | `CHARGE_CURRENT_FILTER_SAMPLES 40U` |

#### 3.3 VBAT静置采样

当充电关闭后，程序等待 `BATTERY_REST_SAMPLE_DELAY_TICKS`（20×50ms = 1s）使端电压稳定，然后采用静置校正算法（`CorrectRestedBatteryVoltage()`）对 VBAT 进行分段线性补偿，消除充电电流引起的线损误差。

### 补4. VBAT电压校准体系

代码实现了三层VBAT校准，非常精细：

**第一层：负载状态混合校准（`CalibrateBatteryVoltage()`）**

由于 LED 导通时电池内阻和线路压降导致 VBAT 读数偏低，代码分别标定了 LED 开启和关闭时的校准系数：

- `BATTERY_LED_ON_CAL_NUMERATOR 10874L` / `BATTERY_LED_ON_OFFSET_MV (-289L)` — LED开启时的斜率和截距
- `BATTERY_LED_OFF_CAL_NUMERATOR 10073L` / `BATTERY_LED_OFF_OFFSET_MV (-34L)` — LED关闭时的斜率和截距

运行时根据 LED PWM 占空比在两组校准值之间线性混合（`blend_permille`），实现平滑过渡。

**第二层：静置电压校正（`CorrectRestedBatteryVoltage()`）**

充电停止后电池端电压会回落，代码使用三段分段线性校正（以 mV 为单位）：

- 输入 ≤ 6400mV：不校正
- 6400mV < 输入 ≤ 7610mV：线性插值，输出偏移 0→+60mV
- 7610mV < 输入 ≤ 8020mV：线性插值，输出偏移 +60mV→+100mV
- 输入 > 8020mV：恒定 +100mV 偏移

**第三层：全局偏置（`BATTERY_FINAL_CORRECTION_MV 50L`）**

所有校准值统一加 50mV 最终偏置，用于匹配万用表实测值。

**校准建议**：如需重新标定，应使用可调稳压电源替代电池，在多个电压点（如 6.0V、7.0V、7.8V、8.2V）同时记录万用表读数和 OLED 显示值，修改对应的 `BATTERY_REST_CAL_*` 和 `BATTERY_LED_*_CAL_*` 宏定义。

### 补5. LED电流校准体系

LED 电流测量采用两段式校准（`CalibrateLedCurrent()`）：

- **低电流段（指示值 ≤ 100mA）**：直接使用原始读数减去偏置（`LED_CURRENT_RAW_HIGH_OFFSET_MA 10L` = -10mA截距）
- **高电流段（指示值 > 100mA）**：应用物理比例因子 `LED_CURRENT_CAL_PHYSICAL_SPAN_MA(188) / LED_CURRENT_CAL_INDICATED_SPAN_MA(200) = 0.94`，补偿运放增益和采样电阻的实际误差

这说明实测中 LED 电流在 100-300mA 区间存在约 6% 的增益误差，通过此分段校准修正。

### 补6. 充电分段导通（Burst）机制

文档仅简述"充电采用分段导通方式"，实际实现如下：

由于实验使用的电源输出能力有限且储能电容需要恢复时间，代码将充电 PWM 周期按 40 个时间片（`CHARGE_BURST_WINDOW_STEPS 40U`）分割：

1. 将目标充电占空比（如 90% = 900/1000）换算为 40 步中的导通步数（900×40/1000 = 36步）
2. 前 36 步：PB0 输出高电平 → Q3 关断 → 太阳能向 VBAT 充电
3. 后 4 步：PB0 输出低电平 → Q3 导通 → 分流太阳能输入 → 外部电源和电容恢复
4. 最小导通步数为 4（`CHARGE_BURST_MIN_ON_STEPS 4U`），即使目标占空比为 10% 也至少导通 4/40 = 10%

每个 Burst 窗口结束时（`g_charge_burst_window_complete`），CV 状态机检查是否可以恢复占空比（每次恢复 `CHARGE_CV_RECOVERY_STEP 20L` 步，约 2%）。

### 补7. 功率通路互锁死区时间

充电通路和 LED 通路之间的切换不是即时的。`ApplyPwmOutputs()` 实现了三步切换流程：

1. 当目标通路与当前通路不同时，先进入 `POWER_PATH_SAFE`（两路均关闭）
2. 等待 `POWER_PATH_BREAK_TICKS`（20×10ms = **200ms**）安全死区
3. 死区结束后才切换到目标通路

此机制确保两条功率通路不会同时导通，防止太阳能直接向 LED 供电或充电电流与 LED 电流叠加损坏器件。

### 补8. OLED I2C总线恢复机制

代码实现了完整的 I2C 总线卡死恢复流程（`RecoverOledI2cBus()`）：

1. 释放 I2C2 外设
2. 将 PB10(SCL)/PB11(SDA) 重新配置为开漏输出 GPIO
3. 在 SCL 上发送最多 9 个时钟脉冲（`OLED_I2C_RECOVERY_PULSES 9U`），直到 SDA 被从设备释放
4. 发送停止条件（START + STOP）
5. 复位 I2C2 外设并重新初始化

此机制在 OLED 因为功率通路切换产生的电磁干扰导致 I2C 总线挂死时自动恢复通信。

### 补9. 启动初始化序列

上电启动顺序（`SunlightR12_Run()`）：

### 补11. 关于电路设计可行性与VSL测量问题

#### 11.1 VSL测量被移除的原因（已验证）

原设计在 SOLAR+ 与 SOLAR- 之间跨接电阻分压测量 VSL（太阳能板电压），但实测发现：
- 当 1N4007 防反二极管导通充电时，VSL 被钳位在 VBAT + Vf(1N4007) ≈ VBAT + 0.7V
- 此时 VSL 不能反映太阳能板的真实开路电压
- ADC_VSL 通道无法有效区分"弱光小电流"和"强光大电流"

因此最终方案删除了 VSL 测量，完全依赖"关断Q3→强行充电→检测充电电流"的周期探测法判定日夜。

#### 11.2 替代方案的理论可行性

在 ADC_VSL 支路接点与 1N4007 二极管之间串联一个分压电阻 R，则：
- 太阳能板开路或弱光时：I ≈ 0，VSL ≈ VSOLAR（可正确测量板电压）
- 太阳能板有输出电流时：VSL = VBAT + Vf + I × R（VSL 高于钳位值，可区分不同光照强度）

此方案理论上可行，但需要仔细选择 R 值：
- R 太小：VSL 仍然接近钳位值，区分度不够
- R 太大：正常充电时在 R 上功耗过大，且会影响充电效率
- 建议 R 取值使得在额定充电电流（如 200mA）下产生约 0.5-1.0V 额外压降

#### 11.3 PCB设计中提及的注意点验证

根据 PCB 技术文档，以下设计决策与代码一致：
- **LM358单芯片复用**：两个运放分别用于 ILED 和 ICHARGE 采样放大
- **ICL7660N负压生成**：为 LM358 提供 -5V 偏置，确保接近 0V 的采样电压正常工作
- **PWM电平上拉**：3.3V→5V 电平转换用于驱动 IRF540N（尽管 5V 不完全导通）
- **ADC保护**：所有 ADC 输入脚（PA0/PA2/PA3）的电压在设计最大工作条件下均不超过 3.3V

### 补12. 代码与电路设计的整体可实施性结论

经过完整审查，得出以下结论：

1. **软件逻辑完整且自洽**：所有状态机（充电、LED、功率通路、日夜检测）逻辑严密，边界条件均有处理。代码中每个安全fallback路径均可追溯到明确的触发条件。

2. **软件与PCB设计匹配**：引脚映射（PA0=VBAT, PA2=ILED, PA3=ICHARGE, PB0=TIM3_CH3充电, PB1=TIM3_CH4 LED, PB10/PB11=I2C2 OLED, PB5-PB8=按键）与 `.ioc` 文件和 PCB 原理图完全对应。

3. **已知的固有局限性**：
   - IRF540N 使用 5V 而非 10V 栅极驱动，MOS 不完全导通，Ron 偏高。在低 VBAT（<6.4V）时 LED 可能无法达到 300mA 目标电流，此为硬件限制，软件无法补偿
   - 日夜检测依赖周期性的 Q3 释放，每次检测需要至少 200ms（恢复等待+采样），期间 LED 必须关闭
   - VBAT 测量精度受 LED 负载状态影响，尽管有三层校准，但在 LED PWM 动态调节时读数仍有波动

4. **可实施的改进建议**：
   - 如需提高 VBAT 测量精度，可在充电关闭的静置窗口期（REST状态的前2秒）进行一次高精度多点采样
   - 如需更快的日夜检测响应，可减小 `SOLAR_START_PROBE_RECOVERY_MS`（当前200ms），但需确认外部电源恢复速度
   - 如需支持更大的 LED 电流（>300mA），需同时修改采样电阻和运放增益，确保 ADC 输入不超 3.3V
