# SUNLIGHT 技术说明

本说明以当前固件源码及 `../PCB/ProPrj_SunLight.epro` 内的原理图、PCB 网络连接为依据。设计目标、代码设定与实物测量分别说明；代码中的经验参数来自本实验板调试，移植时应重新标定。

## 1. 系统功能

本工程用于太阳能充电、储能电容管理和 LED 驱动控制，主要功能包括：

- 根据太阳能充电电流判断白天或黑夜。
- 白天关闭 LED，并根据 VBAT 状态进行充电。
- 黑夜停止充电，并在电池保护允许时驱动 LED。
- LED 电流支持 0～300 mA 设置，步进为 25 mA。
- OLED 显示运行模式、VBAT、日夜状态、充电状态及 LED/充电参数。
- 充电通路与 LED 通路互锁，避免两条功率通路同时导通。

## 2. 主要信号

| MCU 引脚 | 信号 | 功能 |
| --- | --- | --- |
| PA0 | ADC_VBT | 采集 VBAT 电压，原理图网络名为 ADC_VBT |
| PA2 | ADC_ILED | 采集 LED 电流 |
| PA3 | ADC_ICHARGE | 采集充电电流，并用于 DAY/NGT 判断 |
| PB0 / TIM3_CH3 | 充电控制 | 经 Q1（2N3904）反相驱动并联分流 NMOS Q3 |
| PB1 / TIM3_CH4 | LED 控制 | 反相控制 LED MOS |
| PB5～PB8 | S1～S4 | 模式、定时和电流调节按键 |
| PB10 / PB11 | I2C2 | OLED 的 SCL/SDA |
| PC13 | 状态灯 | 正常时呼吸，故障时快速闪烁 |

PB0 为高电平时，Q1 导通并拉低 Q3 栅极，Q3 关断，允许太阳能向 VBAT 充电。PB0 为低电平时，Q1 关断，栅极经电阻上拉，Q3 导通并分流太阳能输入，停止正常充电。C8T6 是 MCU 型号，不是这一级驱动晶体管。

最终原理图没有 ADC_VSL 分压支路，PA1 未接太阳能电压采样；固件也只使用 PA0、PA2、PA3 三路 ADC。PCB 仍有一处 `ADC_VSL` 历史丝印文字，它不代表该采样电路仍然存在。

## 3. 白天和黑夜判断

日夜判断只使用 ADC_ICHARGE：

1. 关闭 LED，并使充电与 LED 功率通路进入安全状态。
2. 关断 Q3，使太阳能输入能够向 VBAT 提供电流。
3. 若此前处于分流状态，等待输入源恢复，并持续检查 VBAT 过压。
4. 对 PA3 的 ADC_ICHARGE 连续采样并计算充电电流。
5. 充电电流不小于 50 mA时判定为 `DAY`，否则判定为 `NGT`。

上电后会尽快执行首次检测。正常情况下，白天约每 5 秒复检一次；黑夜或充电完成状态约每 30 秒复检一次。检测期间 LED 保持关闭。由分流状态释放时，恢复等待约 200 ms，期间约每 10 ms 检查一次 VBAT；随后对充电电流快速采样 8 次。正在充电时的探测走另一条较短的等待路径，不能把所有检测都视作固定 200 ms。

这实际上是在判断“当前 VBAT 下，输入源是否能提供达到门限的充电电流”。弱光、太阳能板端电压不足、VBAT 较高或接线异常都可能得到 `NGT`，不能将其等同于独立照度测量。探测会向电容注入电荷，周期、持续时间和过压退出条件需共同限制；详见文末分析。

## 4. 充电控制

充电状态包括：

- `IDLE`：等待满足充电条件。
- `BULK`：以较高占空比充电。
- `CV`：随 VBAT 上升逐步降低有效充电占空比。
- `REST`：关闭充电后测量静置电压。
- `DONE`：充电完成。

主要控制条件：

- VBAT 不高于 7.8 V 时进入 BULK，目标有效充电占空比为 90%。
- BULK 中 VBAT 达到 7.8 V 后进入 CV。CV 请求占空比上限分段下降：7.8 V 对应 50%，8.2 V 对应 20%，8.3 V 及以上对应 10%；各段之间线性插值。实际请求值还受状态机约束。
- 8.2 V 是设计充电目标，也是代码中的 CV 软高点和完成确认电压；它不表示代码在该读数处无条件立即停充。
- 本板调试后将 `BATTERY_CHARGE_STOP_MV` 设为 8450 mV。当用于保护的校准电压达到该门限时，停止充电并进入静置确认。这是应对实物及采样误差的工程设定，调参背景保留在作者补充中；它是软件判据，不是实际端电压的独立硬件限压。
- VBAT 不低于 8.2 V、充电电流滤波窗口已填满，且电流持续低于 100 mA 约 5 秒后，也会进入静置确认。
- REST 先等待约 2 秒，再以至少 50 ms 间隔采集 60 次电压，约再用 3 秒；满足静置完成条件后进入 `DONE`。DONE 中 VBAT 不高于 7.8 V 连续约 1 秒后允许重启；CV 中不高于 7.75 V 则退回 BULK。

OLED 上的充电占空比表示状态机请求的有效充电比例。充电采用 40 个控制步组成的分段导通窗口，每步名义 50 ms，整窗约 2 秒；90% 对应前 36 步充电、后 4 步分流。PB0 在每步中采用全高或全低，不能将这一窗口解释为把 1 ms PWM 周期分成 40 片。实际导通时间还会受互锁和探测影响。

## 5. LED 控制

LED 默认目标电流为 300 mA，可在 0～300 mA 范围内调节：

- S3：减小 25 mA。
- S4：增加 25 mA。
- 0 mA：保持 LED 关闭。

上电后 300 mA 目标采用直接全导通，此时没有电流闭环；第一次调节电流后进入 PA2 电流闭环，此后即使回到 300 mA 也仍使用闭环。程序根据目标值和实测平均电流逐步调节反相 PWM，占空比显示采用换算后的输出导通比例。该电路调节的是平均电流，PWM 导通瞬间的峰值仍由 VBAT、LED 压降及串联元件决定。

VBAT 低于 6.0 V 时关闭 LED；VBAT 恢复到 6.4 V以上并稳定后重新允许 LED 工作。无论 AUTO、定时还是手动模式，白天状态都会禁止 LED 输出，LED仅在夜晚时允许点亮。

## 6. 按键功能

| 按键 | 功能 |
| --- | --- |
| S1 | 在 AUTO、ON、OFF 三种模式之间切换 |
| S2 | 请求定时点亮，持续约 10 秒 |
| S3 | LED 目标电流减小 25 mA；0 mA 后回到 300 mA |
| S4 | LED 目标电流增加 25 mA；300 mA 后回到 0 mA |

所有 LED 点亮请求仍受日夜判定、VBAT 低压保护、ADC 状态和功率通路互锁限制。

## 7. OLED 显示

OLED 名义上每 500 ms 请求刷新一次，功率切换后的约 200 ms 内会暂缓显示，探测和通信也可能延长刷新间隔。开机初始化时会短暂显示 `SUNLIGHT R12`，进入主循环后显示四行运行信息。

### 7.1 第一行：版本、工作模式、LED 实际状态和运行时间

显示格式：

```text
R12 <MODE> <LED><SSSS>
```

例如：

```text
R12 AUTO ON 0123
R12 ON OFF0456
R12 TIME ON 0789
```

各字段含义如下：

| 显示符号 | 含义 |
| --- | --- |
| `R12` | 当前固件功能版本标识。 |
| `AUTO` | 自动日夜模式。检测为 `DAY` 时请求关闭 LED；检测为 `NGT` 时请求点亮 LED。是否真正点亮仍受 VBAT 低压保护、ADC 状态、充电静置和功率通路互锁限制。 |
| `ON`（模式位置） | 手动点亮请求模式，由 S1 切换得到。它只表示“请求 LED 点亮”，不能绕过白天禁亮、低压保护、ADC 故障或功率通路保护。 |
| `OFF`（模式位置） | 手动关闭模式，不再请求 LED 点亮。 |
| `TIME` | S2 启动的约 10 秒定时点亮请求。计时结束后自动进入 `OFF` 模式。该请求同样不能绕过白天禁亮和其他保护。 |
| `ON`（模式后的状态位置） | 软件当前已经输出 LED 导通指令；该标志由输出比较值推导，不能单独证明 MOS 实际导通或 LED 已经发光。 |
| `OFF`（模式后的状态位置） | 软件当前关闭 LED 输出。即使模式为 `ON` 或 `TIME`，也可能因为白天、低电压、日夜状态未知、ADC 故障、充电静置或通路切换而显示 `OFF`。 |
| `SSSS` | 系统上电后的累计运行秒数，显示范围为 `0000`～`9999`，超过后从 `0000` 重新循环。LED 状态为 `OFF` 时，实际屏幕会紧接着显示数字，例如 `OFF0456`。 |

因此，`R12 ON OFF0456` 并不矛盾：第一个 `ON` 表示模式请求点亮，第二个 `OFF` 表示软件尚未放行输出。

S1 每按一次依次切换：

```text
AUTO → ON → OFF → AUTO
```

### 7.2 第二行：VBAT 电压和 LED 低压保护许可

显示格式：

```text
BAT x.xxV ON
BAT x.xxV OFF
```

| 显示符号 | 含义 |
| --- | --- |
| `BAT` | 储能电容或电池端的 VBAT 电压。数值经过 ADC 分压换算、实测校准和滤波，以伏为单位显示两位小数。 |
| `V` | 电压单位伏特。 |
| `ON` | VBAT 低压保护已经放行，电压条件允许 LED 工作；这不代表 LED 此刻一定点亮。 |
| `OFF` | VBAT 低压保护未放行，LED 必须关闭。VBAT 低于 6.0 V 时立即进入该状态。 |

从 `OFF` 恢复到 `ON` 需要 VBAT 高于 6.4 V 并连续稳定约 1 秒。6.0～6.4 V 之间保持原状态，形成滞回，避免 LED 在门限附近频繁开关。

注意：第二行的 `ON/OFF` 表示“电池电压是否允许 LED 工作”，第一行的 `ON/OFF` 表示“软件是否已输出导通指令”，两者含义不同。实际电流还需看 `L` 读数并结合硬件测量。

### 7.3 第三行：日夜判断和充电状态

显示格式：

```text
SOL DAY BULK
SOL NGT IDLE
SOL --- IDLE
```

| 显示符号 | 含义 |
| --- | --- |
| `SOL` | 太阳能输入及充电控制模块标识。当前版本不再显示 SOLAR 电压。 |
| `DAY` | 判定为白天。程序在释放 Q3 后检测到 ADCICHARGE 不小于 50 mA。白天禁止 LED 输出，并允许充电状态机根据 VBAT 决定是否充电。 |
| `NGT` | `NIGHT` 的缩写，表示判定为黑夜。检测到的充电电流小于 50 mA，此时停止太阳能充电，并允许 LED 按模式和保护条件工作。 |
| `---` | 日夜状态尚未得到有效检测结果，常见于刚上电、正在重新检测、ADC 数据无效或功率通路尚未稳定。状态未知时 LED 不会点亮，正常充电控制也不会直接放行。 |
| `IDLE` | 充电空闲或等待状态。当前没有进入 BULK/CV 充电，可能正在等待有效白天状态、合适的 VBAT 或重新启动条件。 |
| `BULK` | 大电流充电阶段。VBAT 较低时采用较高的有效充电占空比。 |
| `CV` | 恒压调节阶段。随着 VBAT 接近上限，程序逐步降低有效充电占空比。 |
| `REST` | 静置确认阶段。程序暂时停止充电，等待端电压稳定后判断是否真正充满。 |
| `DONE` | 充电完成状态。充电保持关闭，直到 VBAT 下降并稳定达到重新充电条件。 |

如果编译时关闭太阳能充电功能，第三行会显示 `SOL DISABLED`；正常交付版本启用了太阳能充电。

### 7.4 第四行：LED 参数或充电参数

第四行会根据当前日夜及功率通路状态在两种格式之间切换。

#### LED 参数格式

```text
Lxxx/yyy Pzz%
```

例如：

```text
L288/300 P100%
```

| 显示符号 | 含义 |
| --- | --- |
| `L` | LED 电流信息标识。 |
| `xxx` | PA2/ADCILED 测得并经过校准、滤波后的 LED 实际电流，单位为 mA。 |
| `/` | 分隔实际电流和目标电流。 |
| `yyy` | 用户设定的 LED 目标电流，范围为 0～300 mA，S3 步减、S4 步进，每次改变 25 mA。 |
| `P` | LED 的物理导通占空比。由于 PB1 后级为反相驱动，程序已经换算成“LED 实际导通比例”后再显示。 |
| `zz%` | 软件输出的导通占空比，范围为 0%～100%。`P100%` 表示已请求连续导通；它不保证实际电流一定达到目标值，实际电流还会受 VBAT、LED 压降、MOS 和接线压降影响。 |

夜晚时即使低压保护使 LED 关闭，第四行仍可能显示该格式，此时通常会看到实际电流接近 0 mA、`P0%`。

#### 充电参数格式

```text
Dxx% CyyymA
```

例如：

```text
D 90% C185mA
```

| 显示符号 | 含义 |
| --- | --- |
| `D` | 充电“允许导通”的有效占空比。 |
| `xx%` | 充电状态机请求的有效充电比例。它表示最终允许太阳能向 VBAT 充电的时间比例，不是 PB0 原始高低电平比例，也不是某一瞬间 Q3 的状态。 |
| `C` | 充电电流标识。 |
| `yyy` | PA3/ADCICHARGE 测得并经过滤波后的平均充电电流，单位为 mA。 |
| `mA` | 电流单位毫安。 |

`D0%` 只表示当前没有正常充电导通时间，可能原因包括黑夜、`IDLE`、`REST`、`DONE`、日夜检测、VBAT 保护或功率通路互锁，并不一定表示故障。

### 7.5 异常显示

```text
ADC ERROR
```

表示至少一个必要 ADC 通道的采样调用失败。程序会关闭正常充电输出和 LED 输出，并清除日夜判定有效标志。该提示不能识别所有断线、饱和、输入超压或校准不准的情况。

## 8. 安全机制

- 充电通路和 LED 通路切换时先进入两路关闭状态，再等待安全死区。
- ADC 读取失败时关闭充电和 LED。
- 日夜状态未知时关闭 LED，并暂停正常充电控制。
- 太阳能探测期间持续检查 VBAT，避免探测过程造成过压。
- OLED I2C 异常时执行总线恢复，不改变功率通路保护逻辑。
- 系统错误时 Q3进入分流状态，同时关闭 LED。

以上为软件中的保护动作。分流停充并没有将太阳能板与储能端物理断开；实际效果仍取决于 Q3 驱动和输入源能力。

## 10. 最终上传电路的连接与采样

本节依据 [PCB 工程](../PCB/ProPrj_SunLight.epro) 内 `SHEET/787d644ee52acc9d/1.esch`、元件库属性和 PCB 焊盘网络交叉核对。它描述上传文件；器件是否按标称值实装，仍以实验板为准。[PCB 原有技术文档](../PCB/技术文档.md) 中包含早期 VSL 等设计记录，阅读时需结合此最终版本。

### 10.1 充电和 LED 功率回路

```text
SOLAR+ ──┬── D1 ───────── VBAT ── LED ── R31 ── Q2 ── R8 ── GND
         │
         Q3（分流 NMOS）
         │
SOLAR- ──┴── R9 ── GND
```

- Q3 为 IRF540N，漏极接 SOLAR+，源极接 SOLAR-。它跨接输入源，通过拉低太阳能端电压使 D1 停止正常充电；它没有串在电池供电路径中。
- D1 的工程库属性是 **1N5819**，阳极接 SOLAR+、阴极接 VBAT。作者原文中使用 1N4007 的实验记录保留在文末；两者压降不同，分析统一用随电流、温度变化的 $V_D$ 表示。
- LED 回路为 VBAT → 外接 LED → R31（15 Ω）→ Q2 → R8（1 Ω）→ GND。Q2 同为 IRF540N，PB1 经 Q9（2N3904）及上拉电阻反相驱动栅极。
- 本设计没有电感升压级，VBAT 降低后即使全导通，也可能无法达到 300 mA。减小 R31 会同时增大高 VBAT 时的导通峰值电流，不能仅凭平均 PWM 占空比判断器件承受的电流。

IRF540N 的阈值电压只表明在很小测试电流下开始导通；数据手册的低导通电阻指标以 $V_{GS}=10\,\mathrm V$ 为条件。5 V 栅极驱动在本板小电流下可能满足实验，但不能据此保证全部器件、温度和工作点的导通损耗。应实测 $V_{GS}$、$V_{DS}$ 和温升；LED 侧 Q2 的源极还有 R8 压降，实际 $V_{GS}$ 比栅极对地电压更低。[IRF540N 数据手册](https://www.infineon.com/assets/row/public/documents/24/49/infineon-irf540n-datasheet-en.pdf)

分流时，Q3 近似短接输入源。真实太阳能板的短路电流受到其 I–V 特性限制；用实验室稳压电源模拟时，必须设置并核实限流，不能将“大电流稳压源直接被短接”视作正常停充。分流也不自动意味着外部电源已经进入空载恢复状态。

### 10.2 两路电流放大器的极性不同

两路放大器来自同一片 U3（LM358）的两个单元，不能都称为同相放大器。

| 采样量 | 最终原理图连接 | 理想换算关系 |
| --- | --- | --- |
| LED 电流 | R8=1 Ω；U3 的 5 脚接采样点，R5=90 kΩ 反馈、R7=10 kΩ 接地，同相增益 10 | $V_{ADC,LED}\approx 10I_{LED}R_8$ |
| 充电电流 | R9 标为 `600m`（0.6 Ω），连接 SOLAR- 与 GND；R16=10 kΩ 输入、R18=100 kΩ 反馈，U3 的 2 脚为反相端 | $V_{SOLAR-}\approx-I_{CH}R_9$，$V_{ADC,CH}\approx-10V_{SOLAR-}=10I_{CH}R_9$ |

充电时，返回太阳能板负端的电流从 GND 经 R9 流向 SOLAR-，因此 SOLAR- 对地为负电位；反相级把它变为正 ADC 电压。R17=10 kΩ 与 R20=100 kΩ 是**并联**接地，等效约 9.09 kΩ，与 $R_{16}\parallel R_{18}$ 对应，用于偏置电流误差补偿。

代码中充电换算使用增益 10 和 0.5 Ω，图纸 R9 标称 0.6 Ω；这里并列记录图纸标称和代码的工程参数，不据此自动修改调试结果。若另做一块板且确实装入理想 0.6 Ω、增益恰为 10，则当前换算电流约为真实值的 1.2 倍，代码 50 mA 判据约对应真实 41.7 mA。原板是否符合这一假设，需以实装阻值和万用表标定确认。

ICL7660 从外接 +5 V 产生负电源，本板 LM358 使用约 ±5 V 供电。LM358 本身支持单电源及包含负电源轨的输入共模范围，不能把“测量接近 0 V 必须使用 -5 V”作为普遍结论；改变本板供电时，应重新核查零点、输出摆幅和偏置误差。[LM358 数据手册](https://www.st.com/resource/en/datasheet/lm358.pdf)

### 10.3 ADC 范围与功耗的实际边界

- VBAT 经 R11=100 kΩ、R12=47 kΩ 分压，理想 PA0 电压为 $V_{BAT}\times47/147$；VBAT 为 8.45 V 时约 2.70 V。
- 连续 300 mA 的 LED 电流，经 1 Ω、10 倍放大后理想输出为 3.0 V；连续 500 mA 的充电电流，经 0.6 Ω、10 倍放大后也为 3.0 V。这些是指定工作点的估算，不是过压钳位。
- PA2 前的串联电阻、滤波电容，以及 PA3 前的 R19、C6 用于限流或滤波，没有把所有故障电压限制在 ADC 量程内。±5 V 供电的运放可能产生超出 MCU ADC 范围的正、负电压；增大电流或改增益前需重新检查。
- STM32 的 ADC 有效输入范围相对 VSSA、VREF+ 定义，本板通常为 0～约 3.3 V；不能将数字口的“5 V 容忍”套用到这些模拟采样脚。建议为安全起见统一调整为外部上拉3.3V。[STM32F103x8 数据手册](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf)
- R31=15 Ω 在连续 300 mA 时耗散约 $I^2R=1.35\,\mathrm W$，实装需满足功率和散热要求；PWM 情况应按电流有效值计算。图纸库名称或封装不能代替实际功率额定值。R8 在该电流下约 0.09 W，R9 在 500 mA 时约 0.15 W。

## 11. 采样、校准与运行时序

以下实现均可在 [sunlight_r12.c](User/sunlight_r12.c) 中对应到函数和宏。

### 11.1 ADC 平均与电压校准

`ReadAdcAverage()` 等待 TIM3 计数回绕，在一个名义 1 ms 周期内安排 20 个相位点并平均，减少 PWM 相位对读数的影响。VBAT 和充电电流各使用 40 点滑动平均，LED 电流使用 4 点；按正常 50 ms 控制周期估算分别约为 2 秒和 200 ms。滤波会带来延迟，代码另有较快的电压检查，不能把平均值当作所有瞬态的实时值。

VBAT 的标定分为以下几部分：

1. `CalibrateBatteryVoltage()` 使用 LED 开启、关闭两组斜率与偏置，按软件输出占空比混合。两组系数分别为 10874/10000、-289 mV，以及 10073/10000、-34 mV。
2. `CorrectRestedBatteryVoltage()` 在 6.4～7.61 V 区间增加 0～60 mV，在 7.61～8.02 V 区间增加 60～100 mV，超过 8.02 V 后增加 100 mV；不高于 6.4 V 时不作该分段修正。
3. `BATTERY_FINAL_CORRECTION_MV` 另设 50 mV 全局补偿。

这些是本板的经验标定，反映作者在充电、LED 负载及测量条件变化下的调试取舍。软件存在这些系数，并不能单独确定误差具体来自器件、地线、参考电压还是接线压降。移植时应在已知电压点分别记录充电、静置和 LED 工作状态下的万用表值、ADC 值与显示值，再调整系数。

普通停充后的静置取样等待 `BATTERY_REST_SAMPLE_DELAY_TICKS=20`，单位为 10 ms，即约 **200 ms**；第 4 节 REST 完成确认的“2 秒等待＋约 3 秒采样”是另一套时序，两者不能混用。

`CalibrateLedCurrent()` 先令 $x=I_{raw}-10\,\mathrm{mA}$：$x\le0$ 时输出 0；$0<x\le100$ 时输出 $x$；$x>100$ 时输出 $100+(x-100)\times188/200$（单位均为 mA）。高段不是将全部原始电流直接乘 0.94。充电电流没有同类的独立分段校准函数。

### 11.2 PWM、通路切换与功能开关

TIM3 在 72 MHz 定时器时钟下，预分频 71、重装载 999，硬件 PWM 为 1 kHz、1000 级。LED 直接使用该比较值；充电采用第 4 节的 40 步 burst，其有效时间比例粒度为 1/40，即 2.5%，不等同于 LED 的 0.1% 比较分辨率。CV 请求值向上恢复时，每个完整窗口最多增加 20/1000，即 2 个百分点；转换为 40 步后还会量化。

`ApplyPwmOutputs()` 切换充电和 LED 通路时先请求安全状态，再等待名义 200 ms 死区。它是软件互锁，实际 MOS 是否正确关断仍取决于驱动电路。主循环按 10 ms 扫描按键、50 ms 执行控制、500 ms 请求显示；阻塞操作可能拉长时间。TIME 的“10 秒”也由控制步计数得到。

`ENABLE_BATTERY_UNDERVOLTAGE_PROTECTION`、`ENABLE_SOLAR_CHARGING`、`ENABLE_LED_OUTPUT` 当前均为 1。更改这些宏会改变控制行为，不应将关闭太阳能充电简单理解为自动完成了另一种外部供电系统设计。

### 11.3 OLED 初始化与总线恢复

`RecoverOledI2cBus()` 释放 I2C2，将 PB10/PB11 改为开漏 GPIO，最多发送 9 个 SCL 脉冲，再构造 STOP 条件并重新初始化 I2C。初始化尝试的 0x78、0x7A 是 HAL 使用的左移地址，对应 7 位地址 0x3C、0x3D。这能处理部分总线卡住情形，不能修复损坏的屏幕或所有电源干扰。

上电时 `SunlightR12_PreClockInit()` 在系统时钟配置前尽早设置 PB0 低、PB1 高，随后启动 PWM、校准 ADC 并进入主循环；不应将这一步描述为已经证明全部上电瞬态均安全。

#### 原电路为何出现作者观察到的钳制

定义 $P$ 为 SOLAR+ 对 MCU GND 的电压，$S$ 为 SOLAR- 对 MCU GND 的电压，$R_s$ 为负端电流采样电阻，$I$ 为充电电流。忽略分压、栅极偏置及运放输入电流，在 Q3 关断、D1 正向导通时：

$$
P\approx V_{BAT}+V_D,\qquad S\approx-IR_s,
$$

$$
V_{panel}=P-S\approx V_{BAT}+V_D+IR_s.
$$

这说明 SOLAR+ 对地的电压确实被 VBAT 与 D1 的导通压降约束；严格说，太阳能板两端电压还包含负端采样电阻的压降。最终上传图的 D1 属性为 1N5819；若实验板实际使用 1N4007，则代入该实装器件的 $V_D$，而不是固定取 0.7 V。该区别不改变作者对拓扑约束的判断。

这里也应限定原文“ADC 不起作用”的含义：它不能在持续充电时独立反映开路电压或准确反映光照，但 ADC 仍然能测得其接入节点的带载电压。D1 截止后的低输入电压、源是否恢复等信息仍可能有用；删去该支路是本项目选用电流判据后的取舍，不等于所有同类设计的 VSL 测量都无效。

两个参考图的分压下端还有一个容易忽略的问题：它接 **SOLAR-，而非 MCU GND**。设上电阻 $R_t=100\,\mathrm{k\Omega}$、下电阻 $R_b=47\,\mathrm{k\Omega}$，$k=R_b/(R_t+R_b)=47/147$，ADC 对地实际读到：

$$
V_{ADC}=S+k(P-S)=kP+(1-k)S.
$$

因此，仅将 ADC 值乘 $147/47$，只有在 SOLAR- 近似等于 MCU 地时才近似得到板端电压；充电时 $S<0$，会额外引入与电流相关的偏移。这项推导针对参考电路的 VSL 支路；最终板的 PA0 分压下端接 GND，不能用这里的参考地偏移直接解释作者记录的 VBAT 标定误差。

### 4.2 现有“周期释放 Q3、测充电电流”方案

该方案在本电路上可实施，并且符合当前固件：关闭 LED，释放分流，短时允许输入向储能端供电，以 PA3 电流是否达到代码设定门限判断输入是否具备充电能力。它比单看被储能端约束的电压更直接地回答“此时是否有可用充电电流”，也解释了最终原理图为何能够删去 ADC_VSL。

不过，原文“不论 VBAT 为多少”是对实验思路的概括，当前程序实际保留电压约束：用于保护的电压达到 8450 mV 后取消探测请求；从分流恢复的等待中，也会周期检查电压并在达到门限时退出。该值沿用本板调试设定，并不意味着应将其他板的真实端电压都充到 8.45 V。

对储能电容而言，一次探测注入的电荷与电压增量近似为：

$$
\Delta Q=\int_0^{t_p}I(t)\,dt,\qquad
\Delta V=\frac{\Delta Q}{C}\le\frac{I_{max}t_p}{C}.
$$

式中的 $t_p$ 应计入所有实际允许充电的等待和采样时间，$C$ 应使用实装等效电容。探测重复时，平均附加电流约为 $\Delta Q/T$。因此，作者担心反复探测向电容继续充电是有根据的；单纯延长复检间隔只能减小累计注入速度，不能代替单次探测限时、电压余量和及时退出。

其识别边界也要明确：光照存在但源电压不够、储能端接近板的开路电压、限流太小或回路接触不良，都可能低于电流门限。若要求日夜判定不受充电能力和 VBAT 影响，应增加独立光敏检测，或增加能够断开储能端的采样结构。

### 4.3 作者提出的串联电阻方案是否可行

**作为让太阳能侧带载电压呈现更多电流信息的办法，理论上可行；它不能仅靠一个电阻实现真正的开路测量，也不能无代价地消除储能端的影响。** 原文中的电阻应理解为主充电支路串联电阻，而非 ADC 分压支路新增一个电阻。

正确插入位置应是：

```text
SOLAR+ / 采样点 P ── R_add ── D1 ── VBAT
       │
       Q3
       │
SOLAR- / S ───────── R_s ── GND
```

Q3 仍在太阳能板侧跨接 SOLAR+ 与 SOLAR-。

在 Q3 关断、D1 导通，且忽略辅助支路电流时：

$$
P\approx V_{BAT}+V_D+IR_{add},
$$

$$
V_{panel}=P-S\approx V_{BAT}+V_D+I(R_{add}+R_s).
$$

所以，作者写的 $VSL=V_{BAT}+V_D+IR$，若 VSL 指的是**电阻前 SOLAR+ 对 GND 的电压**，就是合理的主回路关系；若指太阳能板两端电压，则还需计入 $IR_s$。这不是“串电阻后电池不再约束太阳能板”，而是电池约束关系中增加了一个可随电流变化的压降。

若还沿用两个参考项目“分压下端接 SOLAR-”的接法，ADC 端的关系进一步变为：

$$
V_{ADC}\approx k(V_{BAT}+V_D)+I\big[kR_{add}-(1-k)R_s\big].
$$

这意味着只增加很小的 $R_{add}$，ADC 对电流的变化甚至可能仍被负端电阻造成的偏移抵消。按 $k=47/147$、$R_s=0.6\,\Omega$ 举例，显式电流项在 $R_{add}\approx1.28\,\Omega$ 时抵消；重新设计时可让分压下端接 MCU GND，从而直接测 $P$；若需要板的两端电压，还应结合负端压降进行换算，并重新核查 ADC 量程。

电阻数值应同时满足可测量压差、输入余量和功耗，不能仅按“额定电流时多出 0.5～1 V”选定：

| 示例阻值 | 200 mA 时压降 / 功耗 | 500 mA 时压降 / 功耗 |
| --- | --- | --- |
| 2.5 Ω | 0.50 V / 0.10 W | 1.25 V / 0.625 W |
| 5 Ω | 1.00 V / 0.20 W | 2.50 V / 1.25 W |

表中是假设电流确能维持的计算值。对目标电流 $I$，太阳能板至少需在该工作点提供约 $V_{BAT}+V_D+I(R_{add}+R_s)$ 的端电压；若电压余量不足，电流会下降。实际工作点由太阳能板 I–V 曲线和回路共同决定，不能先固定原有电流、再假设串联电阻后电流完全不变。

弱光或开路附近若 $I\to0$，额外 $IR_{add}$ 也趋近于零；很小的充电电流既可能来自弱光，也可能来自高 VBAT 或电压余量不足。故此方案能增加带载信息，却不能保证仅凭 VSL 区分强光、弱光，也不能解决现有探测向电容注入电荷的问题。

### 4.4 更适合不同目标的改法与验证方法

- **沿用本实验方案：** 保持最终上传电路，以短时电流探测判断充电能力；依据实装电容、最大输入电流、测量误差和程序响应时间确定探测窗口与电压余量，保留现有实物调试参数作为起点。
- **希望测真正开路电压：** 在充电主路增加可控串联隔离开关；检测时既断开储能端，又关断并联 Q3，再等待并采样。只关断原有 Q3 会释放短接，同时仍允许 D1 充电，达不到这个条件。开路电压也不能独自保证可用输出功率。

若试验作者的 $R_{add}$ 方案，建议先在原定工作范围内比较有、无电阻两种接法，同时记录 $P$、$S$、VBAT、实际电流和 ADC 读数，再检查 $P-V_{BAT}-V_D\approx IR_{add}$；分压换算应按真实参考地进行。还需测电阻、MOS 温升，以及满电附近每次探测前后的真实端电压变化。当前仓库没有这组新增实验记录，因此本节给出的是连接关系和可行性推导，未将它写成已实测成功的改板方案。
